# Vaibhav Kamdi — Cybersecurity Portfolio

A recruiter-focused GitHub Pages portfolio for threat hunting, incident response, detection engineering, threat intelligence, malware analysis and security automation.

## Deploy to GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Copy all files from this folder into the repository root.
3. Replace placeholder GitHub, LinkedIn and email links in `index.html`.
4. Optionally add your `resume.pdf` to the root and link it from `resume.html`.
5. Commit and push.
6. In GitHub: **Settings → Pages → Deploy from branch → main → / (root)**.

## Customize first

- Replace placeholder social/contact links.
- Add your actual resume PDF.
- Add project screenshots/GitHub links.
- Add sanitized threat-hunting case studies.
- Add real blog posts.
- Add your profile photo only if you want one.
- Add a custom domain later if desired.
